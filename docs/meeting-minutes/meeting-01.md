### 3. Project Overview

The Grand Atelier is a Royal and Historical Costume Hire System specialising in luxurious costumes inspired by royal courts, historical fashion and masquerade events.

The application will be developed in C# as a console application, allowing staff to manage costume records, search the catalogue, process rentals and returns, and monitor availability.

The proposed costume categories are:

- Royal
- Historical
- Masquerade

### 4. Proposed Functional Requirements

The team has selected the following features for the project:

1. **Add Costume:** Allow staff to register new costumes with relevant information.
2. **Search Costume:** Search the catalogue by costume ID, category or size.
3. **View Inventory:** Display costume records and available quantities.
4. **Update/Remove Costume:** Modify existing costume details or remove records.
5. **Hire Costume:** Record costume rentals and update availability.
6. **Return Costume:** Process returned costumes and restore available quantities.

### 5. Technical Considerations

The project will use C# and .NET.

The coursework requires the team to design and implement an appropriate custom data structure for storing and searching data, rather than relying entirely on built-in collections.

The team will need to evaluate suitable data structures, develop algorithms, analyse their time complexity and provide pseudocode before implementation.

SQL database integration and unit testing will also be necessary.
